# 소화계 학습용 수정본

`digestive-learning.glb`는 사용자가 제공한 `z-anatomy-1.4.0-digestive.glb`에서 만든 별도 수정본입니다. 현재 `index.html`에 내장된 모델을 교체하지는 않습니다.

## 출처와 변경 내역

- 사용자가 밝힌 원본 프로젝트: [Z-Anatomy](https://www.z-anatomy.com/) / [BodyParts3D](https://lifesciencedb.jp/bp3d/).
- 업로드 파일의 generator: `glTF-Transform v4.4.2`. `1.4.0`은 업로드 파일명에 기재된 버전입니다.
- 업로드 파일의 바이트 해시와 generator를 결과 GLB의 `asset.extras`에 기록했습니다. 업로드 파일 자체에는 저작자·라이선스 고지가 없어, 파일명만으로 특정 배포본과의 일치를 검증한 것은 아닙니다. 위 프로젝트의 출처·라이선스 표시는 사용 시 함께 유지하세요.
- 장면에서 참조하는 12개 메시를 보존하고, 사용하지 않는 메시·재질·버퍼 데이터와 Blender 편집 UI 메타데이터를 제거했습니다.
- 간·위·식도·쓸개·이자·작은창자·큰창자의 7개 그룹을 추가했습니다. 충수는 큰창자 그룹에 포함됩니다. 원래의 영문 이름과 해부학 식별자는 각 부위에 보존하고 한국어 이름을 추가했습니다.
- 현재 앱의 기관별 색상을 GLB 재질에도 적용했습니다. 일반 GLB 뷰어에서 색상이 표시되도록 sRGB 색상을 glTF의 선형 색상으로 변환했으며, 거칠기 0.7·금속성 0을 사용했습니다.
- 정점·법선·삼각형 인덱스의 바이트와 기관의 위치·회전·크기는 변경하지 않았습니다. 압축·폴리곤 감소·기관 형상 재구성은 수행하지 않았습니다.

침샘·입안·직장·항문 등 업로드 파일의 장면에 없는 구조를 새로 만들거나 기존 앱 모델에서 가져와 섞지 않았습니다. 따라서 기존 앱 모델의 모든 구조를 재현하는 파일은 아닙니다.

## 재생성

저장소 루트에서 Python 3 표준 라이브러리만으로 실행할 수 있습니다. 원본 입력 파일은 별도로 보관하세요.

```sh
python3 tools/build_digestive_model.py \
  /path/to/z-anatomy-1.4.0-digestive.glb \
  assets/models/digestive-learning.glb
```

빌더는 결과 GLB를 다시 읽어 모든 사용 정점·법선·인덱스 바이트와 각 부위의 변환이 입력과 같은지 검증합니다. 지원하지 않는 압축·애니메이션·텍스처 구조는 무시하지 않고 실패 처리합니다.

결과: 12개 부위, 7개 기관 그룹, 136,146개 삼각형. 파일 크기는 5,757,452바이트에서 2,468,700바이트로 줄었습니다.

검증: Khronos glTF Validator 오류·경고 0건, 앱에서 사용하는 Three.js GLTFLoader로 로딩 및 WebGL 렌더링 성공. 같은 입력에서 재생성한 GLB가 바이트 단위로 일치하는 것도 확인했습니다.
